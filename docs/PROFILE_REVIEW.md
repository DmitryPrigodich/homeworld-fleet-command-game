# Для будущей сверки карточек

Сверка отложена по просьбе пользователя. Разработку продолжаем по уже полученным фотографиям, книгам и эррате. Это список непроверенных источников, а не требование прислать новые фотографии сейчас.

Нужно проверить обычных лидеров базового набора **отдельно для Kushan и Taiidan**:

- Squadron Leader
- Wing Commander
- Marine Commander
- Marine Captain
- Commander
- Captain
- Commodore
- Carrier Captain
- Vice Admiral
- Admiral
- Station Commander

Для каждого интересуют стоимость, Hand/Play, допустимый класс корабля, вкладки и способности. Иллюстрации Wing Commander и Squadron Leader уже читаются в книге и используются в First Contact. Нужно лишь сверить остальные параметры и фракционные варианты с имеющимися источниками. Обычные Captain/Commander могут отличаться от Veteran Captain/Veteran Commander; окончательную идентичность проверим по значениям и эффектам, без догадок по названиям.

Команды, улучшения, героические/штабные лидеры, сооружения, корабли и нейтральные объекты из уже присланных серий считаются полученными. Полный аудит и различия оригиналов/обновлений записаны в [CARD_INPUTS.md](CARD_INPUTS.md). Их незавершённая реализация не означает, что фотографии отсутствуют. Если конкретный мелкий значок останется неразборчивым, отдельно запишем его имя и поле для сверки.

Дизайн, рубашки и дубли физических экземпляров для механик не нужны. Картинки карточек — необязательный модуль оформления.
